Detecting AI Generated Images

I built this PyTorch workflow for Kaggle's Detect AI vs. Human-Generated Images competition. It records each configuration, metric, plot, and checkpoint so I can compare experiments.

GitHub

What it is

I built this project for Kaggle's Detect AI vs. Human-Generated Images competition. It trains a binary classifier to distinguish AI-generated images from real (human-made) images and keeps a repeatable record of every experiment.

Why it was built

Repeated architecture and configuration experiments are easy to lose if the only saved output is a model checkpoint. This setup keeps the configuration, metrics, plots, and checkpoints together so each experiment can inform the next.

How an experiment works

A run starts from a configuration, trains, and writes a timestamped folder containing the configuration, per-epoch metrics, training curves, confusion matrices, and checkpoints. I inspect that record before choosing the next model, feature, or training change.

Model and feature experiments

I can swap PyTorch image-model architectures and optionally add frequency-domain features using FFT or DCT. Dataset preparation and augmentation live in the same repository.

Result

The best recorded run used Swin V2 Tiny and reached 87.9% validation accuracy. This is validation accuracy, not a Kaggle leaderboard score.

Across systems

The same workflow can run independently on different machines. Each machine writes the same run-folder structure, so results remain comparable without a central scheduler or distributed training.

How it is built

train.py drives the loop, snapshots config.json into runs/<timestamp>/, appends epoch lines to run.txt, and rewrites curves and confusion matrices as the run proceeds. Best and last checkpoints are stored with the same folder.

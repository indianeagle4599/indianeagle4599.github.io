ABOUT

Signal over noise

Good ML starts with understanding the data: what it represents, where it falls short, and what the problem actually needs. Start simple, test assumptions, measure what matters, and change course when the evidence calls for it.

This approach has worked across speech recognition, computer vision, biotech, and multimodal retrieval, using everything from classical methods and deep learning to generative models. The tools change with the problem. What matters is knowing which to use, how to use it, and when to try something else.

I carry that thinking through to execution, from data preparation and experimentation to evaluation, deployment, and usable interfaces. The goal is a reliable system built around real constraints like latency, compute, data quality, and measurable performance.
